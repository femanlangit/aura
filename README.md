# Aura Movie Catalogue

Aura is a browser-based movie catalogue and review application built with HTML, CSS, JavaScript, Node.js, and Express.

## Features

- Search the movie catalogue by title
- View movie information returned by the backend
- Submit a movie rating and review
- Save submitted reviews using file-based storage
- Retain submitted reviews after the application restarts

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- JSON files for application data
